# Transcriptomics Workflow

## Project overview

Customed workflow of transcriptomic analysis

## Directory structure

- `skills/`: skills of specific fields. Each folder corresponds to skills in a specific field.
- `templates/`: templates of skills
- `docs/`: development conventions and overall design
- `scripts/`: code snippets and scripts required by multiple skills.

## Test Environment

The `scv` conda environment is used by default; switch to the `commot` environment if cell-cell communication analysis is involved.
